💡 Today I Learned: Certificate Transparency ▶
Certificate Transparency (CT) is a public auditing framework that requires Certificate Authorities to record every TLS certificate they issue into publicly accessible, append-only logs that anyone can inspect. This lets security researchers, website owners, and browsers verify that a certificate was legitimately issued and quickly spot any unauthorized or fraudulent certificates created for a domain. By monitoring CT logs, defenders can discover within minutes if an attacker has obtained a rogue certificate for their domain — long before it can be used in a phishing or man-in-the-middle attack.
📖 Glossary: BGP · YARA · TTL ▶
BGP — Border Gateway Protocol, the core routing protocol that governs how internet traffic is directed between autonomous systems (networks); hijacking BGP can reroute global traffic through attacker-controlled infrastructure.
YARA — A pattern-matching tool used by security researchers to write rules identifying malware samples based on textual or binary signatures; widely used in threat hunting and automated malware classification.
TTL — Time to Live, a counter embedded in network packets and DNS records limiting how long they exist or are cached; attackers manipulate TTL values in DNS rebinding and evasion techniques to bypass security controls.
