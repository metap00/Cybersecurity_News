💡 Today I Learned: DNS over HTTPS (DoH) ▶
DNS over HTTPS (DoH) encrypts DNS queries by sending them inside normal HTTPS traffic on port 443, so your ISP or a network observer cannot easily see which domain names you are looking up. This solves a long-standing privacy gap: traditional DNS queries travel in plaintext on port 53, making them trivially interceptable and even injectable by attackers on the same network. From a security standpoint DoH is a double-edged sword — it protects user privacy but also makes it harder for enterprise security tools and DNS-based firewalls to block malicious domains, which is why some threat actors now use DoH resolvers as covert channels.
📖 Glossary: DoH · DNS Tunneling ▶
DoH — DNS over HTTPS; a protocol that encrypts domain-name lookups inside standard HTTPS traffic, preventing eavesdroppers from seeing which sites a user visits.
DNS Tunneling — An attack technique that encodes arbitrary data (commands, stolen files) inside DNS query and response packets to smuggle it through firewalls that allow DNS traffic.
