▶ Full analysis & beginner explanation
CVE-2026-104286 exploits a combination of path traversal (CWE-22) and null-byte injection (CWE-158) in Fortinet's FortiMail email security gateway, letting an unauthenticated attacker write arbitrary files to the underlying Linux system. This level of tradecraft suggests organized, well-resourced threat actors operating with a long-term access objective.

The CISA KEV deadline of October 4 has now passed. Organizations that haven't patched are operating past due. Because FortiMail sits at the email perimeter, a compromised appliance gives attackers visibility into all incoming and outgoing email traffic, inbound credentials, and internal communications. Any FortiMail appliance with prior internet exposure before patching should be forensically investigated — look for the sec_monitor superuser account, suspicious binaries, and unauthorized preload entries.

▶ Full analysis & beginner explanation
MALFEX is notable for its persistence and multi-payload architecture. 💡 Today I Learned: Template Injection ▶
Template injection occurs when a server uses a template engine to dynamically generate output — like a webpage or automated email — and an attacker is able to inject their own template syntax into that output, causing the engine to execute malicious logic rather than simply render it as text. Unlike SQL injection (which targets databases) or command injection (which targets the OS shell), template injection exploits the template rendering layer and can often bypass application-level sandboxes to achieve server-side code execution. This week's GitLab AI Gateway flaw (CVE-2026-90970, CVSS 9.9) is a prime example: an authenticated user could craft a Duo Agent Platform flow configuration that escaped the prompt-template sandbox and ran arbitrary commands directly on the gateway server.
📖 Glossary: SSRF · ccTLD · RAT · npm ▶
SSRF — Server-Side Request Forgery; an attack where a hacker tricks a server into making network requests to internal systems on their behalf, often used to reach resources that aren't directly accessible from the internet.
ccTLD — Country Code Top-Level Domain; the two-letter domain suffix assigned to each country (e.g., .uk for the United Kingdom, .gh for Ghana), administered by a national registry authority controlling domain registration for that country.
RAT — Remote Access Trojan; malware that gives an attacker full remote control over an infected computer, typically including screen capture, keystroke logging, file access, and command execution as if they were sitting at the keyboard.
npm — Node Package Manager; the default package manager for the JavaScript/Node.js ecosystem, hosting millions of open-source code libraries that developers install as project dependencies — and a prime target for supply chain attacks.
