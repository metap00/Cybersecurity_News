SAP Commerce Cloud CVE-2026-58231 (CVSS 10.0) Exploited in the Wild Three Days After Patch
🔍 What happened: Attackers began exploiting CVE-2026-58231, a CVSS 10.0 unauthenticated remote code execution flaw in SAP Commerce Cloud's Data Hub Adapter extension, just three days after SAP released patches on its August Security Patch Day.
👤 Who's affected: Enterprises running SAP Commerce Cloud COM_CLOUD 2211 or COM_CLOUD 2211-JDK21 for e-commerce and B2B commerce operations—including retail, manufacturing, and financial services firms—are at immediate risk of server takeover.
✅ What to do: Upgrade to SAP Commerce Cloud 2211.55 or 2211-jdk21.17 immediately; as a short-term measure, configure an IP Filter Set to restrict access to the vulnerable Data Hub Adapter endpoint.
🎯 ATT&CK: [Initial Access] T1190 · Exploit Public-Facing Application
Unauthenticated attackers are directly abusing the exposed Data Hub Adapter HTTP endpoint to inject crafted input and trigger remote code execution on internet-facing SAP Commerce instances—no credentials or prior foothold required.
▶ Full analysis & beginner explanation

The vulnerability resides in SAP Commerce Cloud's Data Hub Adapter, a component that bridges the Commerce Cloud platform with SAP's Data Hub integration layer. An improper authorization weakness allows any unauthenticated external attacker to abuse a default authentication client and submit specially crafted HTTP requests to functions that lack input validation, resulting in arbitrary code execution on the underlying server.

What makes this particularly alarming is the timeline: SAP released the patch on August 12 as part of its monthly Security Patch Day, and threat intelligence firm Defused detected active exploitation attempts against honeypots by August 15—just 72 hours later. There is no known public proof-of-concept exploit, suggesting threat actors reverse-engineered the patch to develop their own. CISA is expected to add this to the KEV catalog given confirmed exploitation.

SAP Commerce Cloud powers e-commerce and complex B2B order management for hundreds of large enterprises. A successful exploit gives an attacker full server-level code execution, from which they can pivot laterally, steal customer data, payment information, and enterprise configuration secrets, or deploy ransomware.

🎓 For beginners: SAP Commerce Cloud is the software that runs the online stores and order systems for many large companies. This vulnerability is like leaving the employee entrance to a store unlocked with no security guard—any random person can walk in, go behind the counter, and do whatever they want. The "patch" is the fix that locks the door, but attackers are already trying the handle within three days of the lock being announced.
CVE-2026-58231 · CVSS: 10.0/10 — Maximum severity score reflects that the flaw is remotely exploitable, requires no authentication, no user interaction, and yields complete system compromise.

Microsoft August 2026 Patch Tuesday: 421 CVEs, One Exploited Zero-Day (CVE-2026-68820), and Wormable DNS RCE
🔍 What happened: Microsoft's August Patch Tuesday addressed 421 vulnerabilities including CVE-2026-68820, a use-after-free zero-day in the Windows Ancillary Function Driver (afd.sys) being actively exploited to elevate privileges, plus CVE-2026-62878, a wormable CVSS 9.8 remote code execution flaw in Windows DNS Server requiring no authentication or user interaction.
👤 Who's affected: All organizations running unpatched Windows systems are at risk—CVE-2026-68820 is being actively weaponized in post-compromise privilege escalation chains, and CVE-2026-62878 puts any internet-facing Windows DNS Server at risk of worm-speed lateral exploitation.
✅ What to do: Apply August 2026 Patch Tuesday updates immediately, prioritizing CVE-2026-68820 (afd.sys) and CVE-2026-62878 (DNS Server); organizations unable to patch DNS Server immediately should restrict external access to port 53 at the perimeter.
🎯 ATT&CK: [Privilege Escalation] T1068 · Exploitation for Privilege Escalation
CVE-2026-68820 is being used in the wild in the post-exploitation phase—attackers who have already landed on a Windows machine trigger the afd.sys use-after-free to gain SYSTEM-level privileges, a critical stepping stone to lateral movement and ransomware deployment.
▶ Full analysis & beginner explanation

August's Patch Tuesday is one of the largest of 2026, covering 421 CVEs across Windows, Office, Azure, and Edge—including 62 rated Critical. The most urgent is CVE-2026-68820, a use-after-free vulnerability in afd.sys, the kernel-mode driver that underpins the Windows Sockets API. Because afd.sys runs at the kernel level, triggering the flaw from a low-privilege process yields SYSTEM rights, making this a high-value component of modern exploitation chains.

CVE-2026-62878, the Windows DNS Server flaw, is rated CVSS 9.8 and carries the "wormable" designation—meaning a single exploit payload could propagate machine to machine across networks that share a DNS server without any administrator interaction. Stack-based buffer overflows in DNS services have historically been weaponized within weeks of disclosure; organizations with internet-facing Windows DNS should treat this as near-critical even without in-the-wild exploitation yet confirmed.

CISA added CVE-2026-68820 to the Known Exploited Vulnerabilities catalog on August 11, 2026, imposing a mandatory remediation deadline on Federal Civilian Executive Branch agencies. The three other disclosed-but-not-yet-exploited zero-days (CVE-2026-62817, CVE-2026-62820, CVE-2026-65789) affect Windows DNS Server and Microsoft QUIC and should be treated as time-sensitive.

🎓 For beginners: Think of afd.sys as the traffic cop inside Windows that manages network connections. This bug lets an attacker trick that traffic cop into promoting them from a regular driver to the head of the police department—gaining full control of the computer. "Wormable" means a different bug (CVE-2026-62878) could spread itself automatically from one computer to the next, like a cold spreading through an office without anyone sneezing directly at you.
CVE-2026-68820 · CVSS: 7.8/10 — High severity for a local privilege escalation; elevated urgency due to active exploitation in the wild confirmed by CISA and Microsoft.

Mustang Panda (HoneyMyte) Upgrades CoolClient Backdoor With Signed Windows Kernel-Mode Rootkit
🔍 What happened: Kaspersky's GReAT team discovered that the Chinese APT HoneyMyte (Mustang Panda / Bronze President) has equipped its CoolClient backdoor with a signed Windows kernel-mode driver rootkit that hides the malware from security tools at the OS's most privileged layer, with victims confirmed in Myanmar, Mongolia, Pakistan, and Russia including government entities.
👤 Who's affected: Government entities, ministries, and diplomatic missions in Southeast Asia, Central Asia, and South Asia are primary targets; the Pakistan and Russia incidents suggest the group is expanding its traditional geographic focus.
✅ What to do: Hunt for the signed driver IOCs published by Kaspersky (Securelist), review Windows driver signing certificates for anomalies, and deploy EDR solutions with kernel-level visibility; organizations in targeted regions should treat any prior PlugX detection as a potential CoolClient re-entry vector.
🎯 ATT&CK: [Defense Evasion] T1014 · Rootkit
HoneyMyte's signed kernel-mode driver takes IOCTL commands from CoolClient's user-mode component to selectively hide files, processes, and network connections from security tools—operating below the visibility layer of most EDR products and making detection and eviction dramatically harder.
▶ Full analysis & beginner explanation

CoolClient first appeared in 2022 and has been exclusively attributed to HoneyMyte, a China-nexus APT that Kaspersky and other researchers track alongside the more widely known Mustang Panda attribution. The group has long favored PlugX as a first-stage implant; CoolClient typically follows as a secondary, persistent backdoor that supports keylogging, clipboard theft, credential harvesting, file management, and plugin-based capability extension.

The newly discovered kernel-mode rootkit is the significant escalation. By obtaining a legitimately signed Windows driver certificate—a process that has become harder since Microsoft tightened cross-signing requirements, but remains achievable through expired certificates or compromised signing keys—HoneyMyte can load code at the kernel layer. At that level, the driver can intercept OS calls and hide its presence from user-mode security tools, including most commercially deployed endpoint detection and response solutions.

The Russia victimology is notable. HoneyMyte has historically targeted governments in Southeast Asia and South Asia aligned with China's geopolitical interests, but targeting of Russian entities may reflect intelligence collection around Sino-Russian diplomatic or military dynamics. The presence of prior PlugX infections in all confirmed CoolClient cases reinforces that this actor uses a staged compromise model.

🎓 For beginners: Antivirus and security software sit "on top of" the Windows operating system, watching what programs do. A kernel rootkit goes underneath those security tools—into the very foundation of Windows—where it can tell the OS to hide certain files and processes. It's like a master illusionist who tricks every security camera in the building into not recording them. The "signed" part means Windows trusts the driver because it has a valid certificate, like a fake but convincing official badge.

INC Ransomware Chains SonicWall SMA 1000 Zero-Days CVE-2026-15409 + CVE-2026-15410 for Root VPN Takeover
🔍 What happened: INC Ransomware (tracked as UTA0533) has been chaining two SonicWall SMA 1000 zero-days—CVE-2026-15409 (CVSS 10.0 unauthenticated WebSocket tunnel bypass) and CVE-2026-15410 (path traversal privilege escalation to root)—to seize full control of VPN gateways, with exploitation beginning June 22 before public disclosure and 893+ total victims now listed.
👤 Who's affected: Organizations using unpatched SonicWall SMA 1000 appliances as VPN gateways—including US, Australian, UAE, Colombian, and Swiss government agencies and private sector organizations—face complete network perimeter compromise.
✅ What to do: Apply SonicWall patches released mid-July 2026 immediately; if patching is delayed, isolate SMA 1000 appliances from the internet and audit for unauthorized wsproxy connections, unfamiliar admin accounts, and lateral movement indicators since June 2026.
🎯 ATT&CK: [Command and Control] T1572 · Protocol Tunneling
CVE-2026-15409 lets an unauthenticated external attacker open an unauthorized WebSocket (wsproxy) tunnel to internal-only services on the SMA 1000 device—effectively tunneling a malicious control channel through the VPN gateway itself, bypassing network segmentation before escalating to root via CVE-2026-15410.
▶ Full analysis & beginner explanation

The two-CVE chain transforms a single unauthenticated HTTP request into full root control of a VPN gateway. CVE-2026-15409 abuses the /wsproxy endpoint, which is supposed to only be reachable from localhost, by circumventing its access restriction. This grants the attacker a WebSocket tunnel into services that should never be externally reachable. CVE-2026-15410, a path traversal in the remove_hotfix workflow of the ctrl-service, then allows the attacker to escalate from a low-privilege service account to root.

Once root on the VPN appliance, INC actors can intercept all VPN credentials in transit, capture network traffic for any connected session, deploy persistent malware, and pivot freely into the protected internal network. Resecurity's analysis shows that exploitation began at least June 22—weeks before SonicWall published the CVEs—meaning hundreds of organizations were silently compromised while considering their VPN appliances fully operational and secure.

INC Ransomware has listed 893 total victims on its leak site as of mid-August, including a significant acceleration since the start of August 2026. The group targets professional services, healthcare, manufacturing, and government, with recent victims spanning six continents.

🎓 For beginners: A VPN gateway is the secure front door to a company's internal network—employees use it to connect remotely. This attack is like finding a hidden service entrance to that front door that was accidentally left unlocked (CVE-2026-15409), slipping inside, and then finding a maintenance loophole that upgrades your access from janitor to building owner (CVE-2026-15410). The attacker can then watch everyone who uses the front door, intercept their keys, and walk anywhere in the building.

💡 Today I Learned: Prompt Injection in AI Agents ▶
Prompt injection is an attack where malicious instructions are hidden inside content that an AI model processes as data—such as a webpage, a document, or a log file—causing the AI to execute the attacker's commands instead of its intended task. Unlike traditional code injection, prompt injection exploits the AI's language understanding: the model cannot reliably distinguish between its operator's instructions and adversarial text that appears in the data it's reading. The GhostJacking technique demonstrated this at DEF CON by embedding attacker commands inside firewall logs and monitoring alerts, tricking AI coding agents into stealing cloud credentials and creating backdoors while believing they were doing legitimate work.
📖 Glossary: PLM · EtherHiding · ClickFix · Rootkit · WebSocket · APT · Prompt Injection ▶
PLM — Product Lifecycle Management; enterprise software that stores and manages product engineering data—blueprints, test results, project timelines—across design and manufacturing cycles; Windchill and FlexPLM are leading PLM platforms targeted by Clop this week.
EtherHiding — A command-and-control obfuscation technique where malware retrieves its C2 server address by querying the Ethereum or Polygon blockchain, making the infrastructure resistant to domain takedowns and IP blacklisting since blockchain data is immutable and globally distributed.
ClickFix — A social engineering malware delivery technique that presents users with a fake CAPTCHA, error dialog, or browser update prompt, then instructs them to copy-paste a malicious command into their terminal or Run dialog, bypassing traditional download-based malware defenses.
Rootkit — Malware that operates at the operating system's kernel level—the most privileged execution layer—allowing it to hide files, processes, and network connections from security tools that run at higher, less-privileged layers; kernel rootkits are among the hardest-to-detect and hardest-to-remove malware categories.
WebSocket — A network protocol providing full-duplex communication over a single persistent TCP connection; used legitimately for real-time web apps, and abused in the SonicWall CVE-2026-15409 attack to tunnel unauthorized connections through the wsproxy endpoint to internal-only services.
APT — Advanced Persistent Threat; a sophisticated, long-duration intrusion campaign—typically nation-state sponsored—characterized by stealthy techniques, specific intelligence objectives, custom malware, and the operational patience to maintain access in victim networks for months or years.
Prompt Injection — An attack class where malicious instructions are embedded in data processed by an AI language model, causing the model to treat attacker-supplied text as legitimate commands; analogous to SQL injection but targeting the AI's instruction-following behavior rather than a database query parser.
