▶ Full analysis & beginner explanation

FortiMail sits at a privileged position in enterprise network architecture — every email entering or leaving the organization passes through it, making it a high-value target for attackers seeking initial access or persistent surveillance. CVE-2026-104286 is a path traversal vulnerability, meaning the software fails to properly sanitize file path characters in a web request, allowing an attacker to write a file to an arbitrary location on disk rather than the intended restricted directory.

In practice, an attacker sends a specially crafted unauthenticated HTTP request that includes path sequences like ../../../ to escape the intended upload directory and plant a malicious file — such as a PHP webshell — in a location that the web server will execute. From that point forward, the attacker has persistent remote code execution on the appliance. Since FortiMail processes all inbound and outbound email, a compromised appliance could silently intercept, modify, or exfiltrate every email in the organization.

Cisco Catalyst SD-WAN Zero-Day CVE-2026-76504 (CVSS 9.8): Authentication Bypass Grants Full Admin Access
🔍 What happened: A critical authentication bypass in Cisco Catalyst SD-WAN Manager exploits improper URI encoding validation to let unauthenticated remote attackers send crafted HTTP requests that completely bypass login checks and gain full administrative API access.
👤 Who's affected: Enterprises using Cisco Catalyst SD-WAN Manager versions 20.9 through 26.2; federal agencies faced a mandatory Oct 3 remediation deadline per CISA's KEV catalog.
✅ What to do: Upgrade SD-WAN Manager to the patched version immediately — Cisco has released fixes for all affected releases and there are no available workarounds.
🎯 ATT&CK: [Defense Evasion] T1036 · Masquerading — URI Encoding Variant
The attacker disguises a request to a restricted API endpoint by percent-encoding characters in a way that bypasses the authentication filter while the backend application still processes it as a privileged admin request — a normalization mismatch that lets attackers masquerade as legitimate traffic.
▶ Full analysis & beginner explanation

Cisco Catalyst SD-WAN Manager is the nerve center of enterprise wide-area networks, controlling routing policies, security rules, and connectivity for potentially hundreds of branch offices and remote sites. Gaining administrative access means an attacker can reroute traffic, create new admin accounts for persistence, or disable security monitoring across the entire enterprise network.

CVE-2026-76504 exploits a subtle flaw in how the SD-WAN Manager validates URL paths before routing requests. URLs can encode special characters in multiple valid ways (for example, a forward slash can be written as / or %2F). The authentication middleware checks whether the incoming URL path matches a list of protected endpoints — but it evaluates the path before decoding these encoded characters. The backend application decodes them first. This means an attacker can send a request to /api/v2/admin%2Fusers, which the security filter sees as an innocuous path, while the application processes it as /api/v2/admin/users with full admin privileges.

This is the fifth actively exploited Cisco SD-WAN zero-day in 2026, highlighting a systemic pattern in how SD-WAN Manager validates input. Attackers who gain admin access can pivot to every connected network segment and site.

💡 Today I Learned: URI Encoding Bypass ▶
When web applications process URLs, they must decode percent-encoded characters (like %2F for a forward slash) before acting on a request — but there is often a mismatch in when security filters decode them versus when the application backend does, creating an exploitable gap. In the Cisco SD-WAN case, the authentication middleware evaluated path strings before decoding, so a request encoded to look like an innocuous URL bypassed the firewall-style check, while the actual application decoded it normally and treated the request as a privileged admin API call. This class of vulnerability, sometimes called a normalization mismatch or HTTP splitting attack, has appeared in web servers, reverse proxies, firewalls, and API gateways for over two decades — yet it keeps reappearing because developers and security teams often use different libraries, at different layers of the stack, that handle URL normalization in subtly incompatible ways.
📖 Glossary: SAML · RedFlick · CosmicPulse · BYOVD ▶
SAML — Security Assertion Markup Language: an XML-based open standard that lets identity providers (like Okta or Azure AD) pass authentication tokens to service providers, enabling single sign-on so users log in once and access many applications.
RedFlick — Microsoft's name for Star Blizzard's updated malware delivery technique, which creates hidden Windows Scheduled Tasks to silently install a backdoor, replacing the group's previous ClickFix fake-CAPTCHA social engineering approach.
CosmicPulse — The backdoor implant installed by Star Blizzard's RedFlick technique; it establishes a covert command-and-control channel from the victim's system back to the attacker's infrastructure and persists via a Windows Scheduled Task.
BYOVD — Bring Your Own Vulnerable Driver: an attack technique where threat actors install a legitimate but vulnerable signed driver onto a victim's system to exploit its kernel-level privileges and disable or bypass security software, as Longleaf did with K7RKScan.
