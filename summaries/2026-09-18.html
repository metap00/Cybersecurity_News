💡 Today I Learned: DNS Cache Poisoning ▶
A DNS cache poisoning attack (also called DNS spoofing) tricks a DNS resolver into storing a forged record that maps a legitimate domain name to a malicious IP address, silently redirecting users who query that resolver without any visible warning. When a victim's computer asks "what is the IP for bank.com?" it receives the attacker's fraudulent answer and connects to a fake site instead, enabling credential theft or malware delivery. The attack's danger was dramatically elevated in 2008 when researcher Dan Kaminsky discovered a flaw allowing an attacker to flood a resolver with thousands of forged responses per second, guessing the transaction ID — a finding that forced an emergency coordinated patch across the entire internet's DNS infrastructure within weeks.
📖 Glossary: RSS · OPML ▶
RSS — Really Simple Syndication; a standardized XML-based web feed format that lets publishers broadcast new content (articles, podcasts, alerts) in a machine-readable form so subscribers can receive updates without visiting each site individually.
OPML — Outline Processor Markup Language; an XML format used to exchange lists of RSS feed subscriptions, allowing users to export their feed collection from one reader and import it into another with a single file.
