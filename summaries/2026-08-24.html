DeadLock Ransomware Stores C2 Config on Polygon Blockchain to Make Infrastructure Seizure Near-Impossible
🔍 What happened: Microsoft has detailed DeadLock ransomware's novel infrastructure: the group stores C2 proxy server addresses and victim-facing leak site links inside Polygon blockchain smart contracts, allowing them to freely rotate servers without updating victims' decryption applications — making law-enforcement infrastructure seizure largely ineffective.
👤 Who's affected: Organizations globally — DeadLock has claimed 96 victims, concentrated in Italy, Spain, Poland, Turkey, and the U.S., primarily targeting mid-market businesses.
✅ What to do: Monitor for DeadLock IOCs from the Microsoft Security Blog; implement egress filtering to block Polygon RPC endpoints (polygon-rpc.com); detect Session messenger network traffic as an anomaly indicator on corporate networks.
🎯 ATT&CK: [Command and Control] T1102 · Web Service
DeadLock queries Polygon blockchain smart contracts as a dead drop resolver to retrieve its current C2 proxy addresses — using the immutable, censorship-resistant blockchain as a communication channel that cannot be seized or sinkholed by defenders.
▶ Full analysis & beginner explanation

DeadLock (first observed July 2025, 96 victims claimed) is a double-extortion ransomware operation that employs Rust-based encryption and Polygon smart contracts for resilient infrastructure. When DeadLock drops its HTML ransom note, it instructs victims to download the Session decentralized messenger app. Internally, that application queries a Polygon smart contract to find the current chat-proxy address — a URL the attacker can update at any time by submitting a blockchain transaction. Traditional law-enforcement takedowns work by seizing C2 servers; here, the "address book" is on a public blockchain no single party controls.

This approach builds on earlier techniques like EtherHiding (which stored malicious scripts on BNB Chain) and represents a maturing sophistication in ransomware C2 architecture. Defenders can attempt to block Polygon JSON-RPC endpoints at the perimeter, but the blockchain's decentralized nature means multiple fallback RPC providers exist. The use of Session — an end-to-end encrypted, metadata-minimizing messenger — for victim communications further reduces attribution risk for the operators.

🎓 For beginners: Normally, police can shut down a criminal's phone line (the C2 server) to cut communications. DeadLock is using a public notice board (the blockchain) that no one owns, to publish their phone number. Even if authorities remove the number from one copy of the board, it exists on thousands of other copies worldwide — making the "phone line" effectively uncensorable.

💡 Today I Learned: Build-Time Code Execution ▶
Build-time code execution is when malicious code runs not when you launch an application, but when you compile one — the moment a developer's machine translates source code into a runnable program. Package ecosystems like Rust's cargo, Python's pip, and Node's npm allow dependency packages to run scripts during the build process to compile native extensions or configure the environment, a legitimate feature attackers exploit by hiding a malicious payload inside a build script. The result: simply adding a dependency to your project can compromise your entire development machine, steal secrets, and plant backdoors in software before it ever ships to users — with no suspicious runtime behavior visible to end-users or security scanners.
📖 Glossary: Smart Contract · Polygon · Double Extortion · Babuk · Troy ▶
Smart Contract — self-executing code stored permanently on a blockchain that runs automatically when predefined conditions are met, used by DeadLock ransomware to store C2 server addresses in an immutable, uncensorable location.
Polygon — an Ethereum-compatible blockchain network with low transaction fees, chosen by DeadLock ransomware to host smart contracts that store C2 proxy addresses, making their infrastructure resistant to seizure or takedown.
Double Extortion — a ransomware tactic where attackers both encrypt victim files AND exfiltrate data beforehand, threatening to publicly leak the stolen data if ransom is not paid — giving them leverage even if victims restore from backups.
Babuk — a ransomware family whose source code leaked in 2021 and has since been adapted by dozens of threat actors; the China-nexus group exploiting VMware CVE-2026-59310 deployed a Babuk-derived variant against compromised ESXi servers.
Troy — a newly documented Lazarus Group backdoor supporting 17 remote commands including interactive shell, process injection, file transfer, and code injection into running processes, deployed alongside the FudModule rootkit in Operation Dream Job intrusions.
