▶ Full analysis & beginner explanation

This vulnerability is alarming precisely because it subverts a security appliance. The Cisco Secure Email Gateway sits at the network perimeter, tasked with inspecting and filtering inbound emails for malware and phishing. With a CVSS score of 9.8 and no authentication required, exploitation is trivial: send a crafted email, receive a root shell on the gateway. BambooToken routes all C2 traffic through MQTT — an IoT messaging protocol rarely inspected by enterprise security tools — allowing it to masquerade as legitimate industrial or smart-device traffic and evade detection for years on targeted networks.
▶ Full analysis & beginner explanation

BambooToken represents a sophisticated evasion strategy: by choosing MQTT as its communications protocol, the malware authors identified a blind spot in most enterprise security stacks. MQTT was designed for IoT devices like industrial sensors and smart building systems — it's lightweight, efficient, and travels on ports that many firewalls and intrusion detection systems do not scrutinize. An enterprise with MQTT-enabled devices (common in manufacturing, building automation, or lab environments) would have no reliable way to distinguish BambooToken's malicious traffic from legitimate device telemetry.

The malware's DLL sideloading vector through Tendyron OnKey software — a Chinese-made USB security key product widely used in financial sector authentication — is particularly significant. It suggests the threat actor has deep knowledge of the target environment's tooling, pointing to either prior reconnaissance or insider knowledge. The combination of keylogging, clipboard monitoring, audio recording, webcam capture, and screenshot capabilities creates a comprehensive espionage platform suited for stealing proprietary business information, legal strategy, or financial data.

Black Lotus Labs found the malware on VirusTotal in early 2026 despite it being active since 2023 — a three-year detection gap that underscores how effectively the MQTT channel evaded traditional detection. The China alignment assessment is based on tooling and targeting patterns rather than definitive attribution.

🎓 For beginners: MQTT is like a quiet walkie-talkie channel that factories use to communicate with sensors on machines. Authenticated attackers exploit insecure file permissions in the Acronis cPanel plugin to escalate from a low-privilege hosting account to root on the underlying Linux server, enabling access to all hosted sites and customer data on the same server.
▶ Full analysis & beginner explanation

This vulnerability is particularly dangerous in shared hosting environments where multiple customers share the same physical Linux server. Normally, a hosting customer can only access their own files — a sandboxed portion of the server — because Linux permission systems enforce strict boundaries. CVE-2026-87886 breaks this isolation: an attacker with any valid cPanel account can exploit insecure file permissions in the Acronis backup plugin to escalate to root, instantly gaining access to every other customer's data on the server.

The hosting ecosystem is an attractive target because compromising one server can yield hundreds or thousands of websites' data simultaneously. Attack chains often begin with purchasing a cheap shared hosting account specifically to exploit privilege escalation vulnerabilities, then pivoting across all co-hosted sites. Backup plugins are especially high-risk because they require elevated permissions by design and often run as privileged system daemons.

💡 Today I Learned: Heap Buffer Overflow ▶
A heap buffer overflow is a memory corruption vulnerability where a program writes more data into a heap-allocated memory block than that block can hold, causing adjacent memory to be overwritten. Attackers deliberately craft inputs that trigger this overwrite — potentially corrupting pointers, function addresses, or security metadata in ways that redirect the program's execution to attacker-controlled code. Today's CVE-2026-85880 (Windows ALPC) and CVE-2026-58704 (Pixel modem) both exploit heap memory corruption flaws to achieve privilege escalation, illustrating how a low-level memory management mistake can cascade into full system compromise.
📖 Glossary: RCE · KEV · LPE · MQTT · cPanel ▶
RCE — Remote Code Execution: an attack class where an adversary runs arbitrary code on a target system from a remote location by exploiting a vulnerability, without needing physical access or prior authentication.
KEV — Known Exploited Vulnerabilities: CISA's authoritative public catalog of CVEs confirmed as actively exploited in the wild; U.S. federal agencies are legally required to remediate KEV entries within mandated timeframes (typically 3–14 days).
LPE — Local Privilege Escalation: an attack technique that allows a user or process already on a system with limited permissions to gain elevated rights — often administrator or root — by exploiting a vulnerability in the OS or an installed application.
MQTT — Message Queuing Telemetry Transport: a lightweight publish/subscribe messaging protocol originally designed for IoT and low-bandwidth sensor devices; increasingly abused by malware as a stealthy C2 channel because security tools rarely deep-inspect MQTT traffic.
cPanel — A widely-used web-based control panel for web hosting management that allows administrators to configure domains, email, databases, and server applications; its plugins frequently run with elevated system privileges, making them attractive targets for privilege escalation attacks.
