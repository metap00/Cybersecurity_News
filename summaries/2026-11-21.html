💡 Today I Learned: Fuzzing ▶
Fuzzing (or fuzz testing) is an automated software testing technique that feeds a program large amounts of random, malformed, or unexpected data to trigger crashes, hangs, or memory errors that reveal security vulnerabilities. Tools like AFL++ and libFuzzer continuously generate mutated inputs and monitor for unusual behavior — a process that has uncovered thousands of real-world CVEs in browsers, kernels, and network stacks. Because fuzzing explores code paths that human testers often miss, it has become a standard first step in security-focused code review and is now integrated into major open-source projects through initiatives like Google's OSS-Fuzz.
📖 Glossary: Fuzzing · FIDO2 · WebAuthn ▶
Fuzzing — An automated testing method that bombards software with random or malformed inputs to discover crashes and exploitable vulnerabilities.
FIDO2 — A set of open authentication standards (from the FIDO Alliance) that enable strong, passwordless login using public-key cryptography on hardware security keys or device biometrics.
WebAuthn — The W3C web standard that is the browser/platform component of FIDO2, allowing websites to authenticate users with FIDO2-compliant credentials instead of passwords.
