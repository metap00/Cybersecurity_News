💡 Today I Learned: Fuzzing ▶
Fuzzing is a software testing technique where automated tools generate massive quantities of random, unexpected, or malformed inputs and feed them into a program to trigger crashes, hangs, or other unexpected behavior that may indicate a security vulnerability. When a fuzzer causes a crash, researchers analyze the failing input to determine whether an attacker could exploit the underlying flaw — many critical CVEs in browsers, operating systems, and network libraries have been discovered this way. Open-source fuzzers such as AFL++ and libFuzzer are routinely used by both security researchers and development teams to harden software before it ships, making fuzzing one of the most cost-effective vulnerability discovery methods available today.
📖 Glossary: Fuzzer · SAST ▶
Fuzzer — an automated tool that generates random, unexpected, or malformed inputs and feeds them into software to discover security vulnerabilities or crashes.
SAST — Static Application Security Testing; a method of analyzing source code or compiled binaries for security flaws without executing the program, often integrated into CI/CD pipelines.
