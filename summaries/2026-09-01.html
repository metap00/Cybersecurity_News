💡 Today I Learned: Shadow Stack ▶
A Shadow Stack is a second, hardware-protected copy of function return addresses that a processor maintains in a region of memory programs cannot directly write to. When a function finishes executing and tries to return, the CPU compares the return address on the regular call stack against the shadow copy — if they differ, it knows a memory-corruption attack has tampered with the stack and halts execution immediately. This mechanism, implemented in Intel's Control-flow Enforcement Technology (CET) and ARM's Pointer Authentication, stops an entire class of exploits called Return-Oriented Programming without requiring any changes to application source code.
📖 Glossary: Shadow Stack · ROP · CFI · CET ▶
Shadow Stack — A hardware-protected duplicate of function return addresses that the processor maintains separately from the regular call stack to detect tampering.
ROP (Return-Oriented Programming) — An exploitation technique that chains together small existing code snippets ("gadgets") already present in a program's memory to execute malicious logic without injecting new code.
CFI (Control Flow Integrity) — A security policy that restricts which code locations a program may jump or call to, preventing attackers from redirecting execution flow to unintended targets.
CET (Control-flow Enforcement Technology) — An Intel hardware feature, enabled at the CPU level, that implements Shadow Stack and Indirect Branch Tracking to harden binaries against memory-corruption exploits.
