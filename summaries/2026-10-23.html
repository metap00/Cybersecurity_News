Arista Warns of Critical VeloCloud SD-WAN SQL Injection Zero-Day Exploited in Attacks (CVE-2026-114625, CVSS 9.9)
🔍 What happened: A SQL injection zero-day (CVSS 9.9) in Arista's VeloCloud Orchestrator allows any authenticated user — even with the lowest read-only role — to escalate to full operator-level control of the SD-WAN management plane, with active exploitation confirmed and attacker IPs published in the advisory.

✅ What to do: Patch immediately to the fixed releases; block confirmed attacker IPs 74.82.197.86 and 38.54.50.151; restrict VCO web interface access to trusted networks only until patched.

▶ Full analysis & beginner explanation

SD-WAN orchestrators like Arista's VeloCloud are the centralized management planes for enterprise branch networking — they control traffic routing, VPN tunnels, and firewall policies for potentially hundreds of branch offices from a single web interface. Compromise of the orchestrator doesn't just expose one server; it can expose an organization's entire wide-area network topology, traffic patterns, and VPN credentials.

CVE-2026-114625, disclosed in Arista's October 22 advisory, is a SQL injection flaw in the VCO web interface that breaks the privilege model at its foundation. Unlike most SQL injection bugs requiring administrator access, this one activates with the lowest possible "Enterprise Read Only" role — a credential that might be issued to vendors, auditors, or read-only monitoring accounts. An attacker crafts a malicious request to manipulate the underlying database query and grants themselves operator-level privileges. Arista confirmed active exploitation in the wild and named two specific IP addresses being used in ongoing attacks.

Fixes are available for all supported branches (5.2.3.18, 6.1.3.10, and 6.4.2.12). Hosted and Dedicated cloud-managed instances have already been patched automatically by Arista. On-premises deployments require immediate manual action. Until patched, restricting the VCO web interface to trusted IP ranges is the single most important mitigation.

🎓 For beginners: Imagine your company's entire branch-office network is managed through one web portal — one login to control internet routing for all your offices. This vulnerability lets anyone with even a "view-only" guest login instantly become the full administrator of that portal. An attacker could reroute your company's internet traffic through their servers, shut down remote worker VPN connections, or spy on all internal network activity.

BeyondTrust Remote Support is widely used by IT helpdesks and managed service providers for privileged remote access to customer systems. Many deployments also use its built-in secrets vault to store privileged credentials — passwords, API keys, and certificates used during support sessions. This combination of remote access capability and a rich credential store made it a high-value target for Chinese state-sponsored espionage.

CVE-2026-102764 is an improper origin validation flaw in the appliance's internal messaging component that requires no authentication — any attacker with network access to the web interface can exploit it to perform arbitrary file operations. The group is known for serially targeting edge device zero-days across vendors, having previously exploited Citrix NetScaler and Ivanti products in similar campaigns.

🎯 ATT&CK: [Initial Access] T1195.003 · Supply Chain Compromise: Compromise Software Dependencies
Attackers hijacked maintainer accounts to publish a trojanized package to PyPI and Docker Hub — a direct instance of T1195.003, delivering malware through a trusted software dependency that thousands of AI infrastructure deployments install in good faith.
▶ Full analysis & beginner explanation

LiteLLM is one of the most widely used open-source proxies for routing AI API requests — it lets developers call multiple LLM providers (OpenAI, Anthropic, Mistral, and others) through a single unified interface. This makes it a common dependency in AI-powered applications, and its broad access to AI provider credentials makes it a particularly attractive target.

Attackers obtained GitHub CLI OAuth tokens from three maintainers' accounts and used them to trigger the private release workflow, publishing trojanized wheels to PyPI and poisoned Docker Hub tags. The malicious payload used a Python .pth (path configuration) file named cook.pth — placed in site-packages so it executes at startup of any Python process. A 16-module stealer then collects cloud provider credentials, AI API keys, Kubernetes configs, SSH keys, LiteLLM's proxy database credential tables, and browser-stored secrets; it encrypts the collected data and posts it to a lookalike exfiltration domain. On Linux and macOS, a remote-code loader also runs hourly for persistent access.

PyPI removed the package within about two hours of detection. No CVE, national CERT alert, or CISA KEV listing had been issued as of October 22. This is LiteLLM's second supply-chain compromise in 2026 — malicious versions 1.82.7 and 1.82.8 were published in March — suggesting the maintainer account security posture warrants serious ongoing attention. Any environment that installed 1.107.0 should be treated as fully compromised until all secrets are rotated and the system is rebuilt.

Advisory AA26-293A was issued October 20 by a coalition including the FBI, CISA, the U.S. Secret Service, Germany's Landeskriminalamt Rheinland-Pfalz, the UK's National Crime Agency, and the UK's North West Regional Organised Crime Unit — signaling active international law enforcement engagement with the group, even if no arrests or infrastructure takedowns have yet been announced.

SafePay's intrusion chain is methodical: initial access typically comes from stolen or credential-stuffed VPN logins, or exploitation of unpatched edge devices such as Cisco ASA/FTD appliances. This "scorched earth" approach to backup destruction is designed to leave victims with no realistic recovery path other than paying the ransom.

The 600+ victim count is certainly an undercount: ransomware groups typically only publish victims who refuse to pay on their leak sites, so organizations that pay — often the majority — never appear in public tallies. The international advisory scope suggests SafePay's reach spans North America and Europe at minimum.

Without backups, companies face a stark choice: pay the ransom or lose their data permanently.

💡 Today I Learned: Webshell ▶
A webshell is a small malicious script that attackers plant on a compromised web server — it lets them issue commands through a standard web browser as if sitting at the server's keyboard, with no need to re-exploit the original vulnerability on every visit. Because webshell traffic looks identical to ordinary web requests (HTTP/HTTPS to the same port and service), it can hide in server logs for weeks or months while attackers quietly steal data, dump credentials, and move laterally through internal systems. ARMORY CASTLE demonstrated exactly this with SAWFLY: after exploiting the BeyondTrust zero-day CVE-2026-102764, they installed the custom SAWFLY webshell and used it for 30 undetected days to methodically harvest credentials from the appliance's secrets vault — traffic invisible from normal HTTPS monitoring.
📖 Glossary: CVSS · APT · Zero-Day · SQL Injection · Privilege Escalation ▶
CVSS — Common Vulnerability Scoring System; a standardized 0–10 scale for rating vulnerability severity: 9.0–10.0 is Critical, 7.0–8.9 is High, 4.0–6.9 is Medium, and below 4.0 is Low.
APT — Advanced Persistent Threat; a sophisticated, long-duration attack campaign typically carried out by nation-state actors or well-resourced criminal groups who maintain covert access to networks for extended periods to conduct espionage or sabotage.
Zero-Day — A software vulnerability that is unknown to the vendor, with no patch available; called "zero-day" because defenders have had zero days to prepare or deploy a fix before it is discovered and exploited.
SQL Injection — A code injection attack that manipulates database queries by inserting malicious SQL statements into user-controlled input, potentially enabling data theft, authentication bypass, or privilege escalation as seen today in the Arista VeloCloud flaw.
Privilege Escalation — The act of exploiting a vulnerability or misconfiguration to gain higher system permissions than originally granted, such as moving from a read-only user to a full system administrator — the core impact of CVE-2026-114625.
