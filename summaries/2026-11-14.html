💡 Today I Learned: DNS Cache Poisoning ▶
DNS Cache Poisoning is an attack where a malicious actor injects forged DNS records into a resolver's cache, causing it to return a fraudulent IP address for a legitimate domain — silently redirecting users to attacker-controlled servers. The attack exploits the fact that DNS resolvers cache answers to speed up future lookups, so a poisoned entry can misdirect thousands of users until the cache expires. Modern defenses include DNSSEC (which cryptographically signs DNS records), randomising the source port and query ID in resolver requests, and monitoring for anomalous DNS response patterns.
📖 Glossary: DNS Resolver · Cache Poisoning · DNSSEC ▶
DNS Resolver — A server that receives DNS queries from clients and recursively looks up the answer, caching results to reduce lookup time for subsequent requests.
Cache Poisoning — An attack that inserts malicious or false data into a caching system (such as a DNS resolver) so that subsequent lookups return attacker-controlled results.
DNSSEC — DNS Security Extensions; a suite of IETF specifications that cryptographically sign DNS records, allowing resolvers to verify that responses have not been tampered with.
