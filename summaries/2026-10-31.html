💡 Today I Learned: Memory Tagging Extension (MTE) ▶
ARM's Memory Tagging Extension (MTE) is a hardware feature built into modern ARM processors that assigns a 4-bit "color" tag to every 16-byte chunk of memory and embeds a matching tag in the top bits of every pointer. When code accesses memory, the CPU hardware instantly checks that the pointer's tag matches the allocation's tag — if they differ, a fault is raised before any damage can occur. This elegant mechanism catches entire classes of memory bugs — use-after-free errors, buffer overflows, and heap corruption — at near-zero performance cost, making exploitation of memory-safety vulnerabilities dramatically harder even when attackers find the underlying bug.
📖 Glossary: MTE · UAF · EPSS ▶
MTE — Memory Tagging Extension; an ARM processor feature that assigns color tags to memory allocations and pointer references, catching memory safety violations in hardware at runtime.
UAF — Use-After-Free; a memory corruption bug where code continues to access a memory region after it has been freed, often exploitable by attackers to redirect execution flow.
EPSS — Exploit Prediction Scoring System; a data-driven model maintained by FIRST that estimates the probability a given CVE will be actively exploited in the wild within the next 30 days, helping defenders prioritize patching.
