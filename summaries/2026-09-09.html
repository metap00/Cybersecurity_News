💡 Today I Learned: Certificate Transparency ▶
Certificate Transparency (CT) is an open framework that requires every SSL/TLS certificate issued by a Certificate Authority (CA) to be recorded in publicly auditable, append-only cryptographic logs before browsers will trust it. Web browsers verify that a certificate appears in at least two of these logs when establishing a secure HTTPS connection, making it detectable within seconds if a rogue CA issues a fake certificate for any domain. This means even a nation-state that compromises a trusted CA cannot silently mint fraudulent certificates — the forgery would appear in the global CT logs and trigger alerts from monitoring services watching for unauthorized certificates.
📖 Glossary: FIDO2 · EDR · C2 ▶
FIDO2 — Fast Identity Online 2; an open authentication standard using public-key cryptography that replaces passwords with hardware tokens or biometrics, making phishing and credential theft effectively impossible.
EDR — Endpoint Detection and Response; a security platform that continuously monitors device activity (processes, network connections, file changes) to detect threats in real time and enable rapid incident response.
C2 — Command and Control; the infrastructure (servers, domains, encrypted channels) attackers use to remotely issue instructions to malware on compromised machines and receive stolen data back.
