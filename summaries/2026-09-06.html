💡 Today I Learned: Living off the Land (LotL) ▶
"Living off the Land" is an attack strategy where adversaries exclusively use tools already built into the target operating system — things like PowerShell, WMI, certutil, or native scripting engines — rather than dropping custom malware that could be caught by antivirus. Because these legitimate tools are used by system administrators every day, malicious commands blend into normal activity and are far harder to flag with signature-based detection. Security teams counter LotL attacks by establishing behavioral baselines for tool usage and alerting on anomalies, such as certutil downloading remote files or PowerShell spawning from an unexpected parent process.
📖 Glossary: LotL · BEC · TOCTOU · DNS Sinkhole ▶
LotL — Living off the Land; using built-in OS tools such as PowerShell, WMI, or certutil for malicious purposes to evade signature-based detection.
BEC — Business Email Compromise; a social-engineering scam where attackers impersonate executives or trusted partners to trick employees into fraudulent wire transfers or sensitive data disclosures.
TOCTOU — Time-of-Check Time-of-Use; a race-condition vulnerability where the state of a resource changes between the moment it is verified and the moment it is actually accessed or used.
DNS Sinkhole — A DNS server configured to return false responses for known-malicious domains, redirecting botnet traffic away from attacker infrastructure to a controlled, monitored endpoint.
