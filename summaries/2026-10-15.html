Attacker Chains Three Ivanti Zero-Days for Unauthenticated Root Access on Fully Patched VPN
🔍 What happened: Threat actor UTA0576 chained three zero-day vulnerabilities in Ivanti Connect Secure (tracked as CVE-2026-104935) to gain unauthenticated root access on fully patched VPN appliances, operating since October 3 without installing any persistent malware.
👤 Who's affected: Organizations running Ivanti Connect Secure VPN appliances, especially those whose appliances store Active Directory credentials, LAPS passwords, and BitLocker recovery keys.
✅ What to do: Apply the October 13 patch for CVE-2026-104935 immediately; perform forensic investigation using memory and disk images; monitor for lateral movement originating from VPN appliances; note that one privilege-escalation flaw in the chain remains unpatched.
🎯 ATT&CK: [Credential Access] T1003 · OS Credential Dumping
UTA0576 specifically targeted LAPS passwords, BitLocker recovery keys, and Active Directory credentials stored on the compromised appliance — classic credential dumping to enable broader network compromise.
▶ Full analysis & beginner explanation

Volexity discovered the attack campaign on October 13, 2026, after noticing suspicious activity on a monitored customer's network. The attackers targeted Ivanti Connect Secure build 22.8R2.4 — the latest available at the time — meaning even fully patched organizations were vulnerable. The exploit chain begins with an authentication bypass and a remote code execution bug (together tracked as CVE-2026-104935), which elevates the attacker to the VPN service's low-privilege user; a third unpublished privilege escalation flaw then raises access to full root.

What makes UTA0576 stand out operationally is their deliberate avoidance of persistence. Rather than installing a web shell or backdoor that defenders could detect, they re-ran the entire exploit chain from scratch for every single command they needed to execute. After each session they also deleted log entries on the appliance, making traditional log-based detection impossible. Volexity reconstructed the attack timeline only by analyzing memory dumps, disk images, and core dump files.

The stolen data included Active Directory domain credentials, LAPS (Local Administrator Password Solution) passwords, and BitLocker recovery keys — exactly the credentials needed to move laterally through an enterprise and decrypt encrypted drives. Two of the three vulnerabilities were patched on October 13; the third privilege escalation flaw has no patch yet and Ivanti says a fix is weeks away.

🎓 For beginners: Imagine a locked building where the security system itself has a hidden flaw. The attacker found three flaws they could combine: one to get through the front door without a key card, one to move past an inner checkpoint, and one to get master keys to the whole building. They were so careful that instead of copying the master key (installing malware), they re-picked the locks each time they wanted something — and then erased the security camera footage after each visit, leaving no trace for weeks.
CVE-2026-104935 · CVSS: 8.6/10 — Critical severity covering the authentication bypass + RCE pair; third privilege escalation CVE pending assignment.

October 2026 set a new record for Microsoft's monthly security update cycle: 1,413 CVEs addressed in a single Patch Tuesday, surpassing any previous month. Of these, approximately 69–80 are rated Critical (sources differ on the exact count), with the largest concentrations in Windows (1,102 CVEs), Microsoft Office (134), and SharePoint Server (36). The scale reflects both an expanded attack surface as Windows becomes more modular and Microsoft's growing commitment to disclosing vulnerabilities in third-party components bundled with Windows.

The patch receiving most urgent attention is CVE-2026-96951, a Windows Shell security feature bypass rated CVSS 8.8. Dark Reading reports it was discovered by Claude AI. Attackers are already exploiting it in the wild to deliver malicious files that bypass Windows' Mark-of-the-Web (MotW) protection. When a file is downloaded from the internet, Windows attaches a MotW tag; SmartScreen uses this to display a warning before the file runs. CVE-2026-96951 strips or corrupts that tag, silencing the warning and enabling execution. This makes it ideal for phishing campaigns delivering weaponized archives or Office macros.

A second zero-day, CVE-2026-108398 (.NET Framework security feature bypass), was publicly disclosed prior to patching but has no confirmed exploitation. Administrators running SharePoint Server on-premises should treat that product as a high priority given its 36 CVEs and historically frequent use as a ransomware entry point.

🎓 For beginners: Windows puts a secret "came from the internet" sticker on every file you download, and shows you a scary warning before running it. This vulnerability lets attackers remove that sticker, so Windows runs the malicious file as if you had created it yourself — no warning, no security check. Think of it as forging the "inspected by customs" stamp on a package to bypass border security entirely.

JetBrains TeamCity is a popular continuous integration and continuous delivery (CI/CD) platform used by development teams to automate the building, testing, and deployment of software. CVE-2026-63077 carries a maximum-severity CVSS score of 9.8, indicating unauthenticated remote code execution with no user interaction required — the worst possible combination for an internet-facing server. Ransomware actors have targeted TeamCity consistently since 2023, recognizing that CI/CD servers occupy a uniquely privileged position: they have credentials for cloud platforms, production databases, code repositories, and container registries, all in one place.

The exploitation pattern observed in TeamCity incidents follows a predictable arc: initial RCE is used to create a new administrator account or extract existing credentials, then attackers enumerate all connected build agents (which are often production-adjacent virtual machines), insert malicious build steps that run automatically on the next scheduled pipeline trigger, and use the legitimate deployment trust to push ransomware or exfiltrate intellectual property before demanding payment.

This CVE represents a recurring pattern at JetBrains — previous critical TeamCity vulnerabilities (notably in 2023 and 2024) were exploited within hours of public disclosure. The October 2026 iteration confirms that threat actors monitor TeamCity advisories as closely as security teams do, and patch windows are extremely narrow.

💡 Today I Learned: Log Tampering ▶
After compromising a system, attackers routinely delete or alter the event logs that record their activity — a technique called log tampering — to erase forensic evidence and buy more time inside the network. Today's Ivanti breach took this to an extreme: rather than installing a persistent backdoor that might be detected, UTA0576 re-ran their entire exploit chain fresh for every command and then deleted each log entry, making their intrusion nearly invisible to defenders relying on standard SIEM monitoring. Security teams counter this by configuring real-time log forwarding to immutable, remote storage — once a log line is shipped to a write-protected SIEM, even an attacker with root access to the compromised device cannot erase it.
📖 Glossary: LAPS · SSRF · Cobalt Strike · BloodHound ▶
LAPS — Local Administrator Password Solution, a Microsoft tool that automatically manages and rotates unique local administrator passwords for each domain-joined computer, preventing attackers who compromise one machine from using the same password to log into every other machine in the organization.
SSRF — Server-Side Request Forgery, an attack where a vulnerable web server is tricked into making HTTP requests to internal resources on behalf of the attacker, allowing them to reach internal systems that are normally blocked from external access by firewalls.
Cobalt Strike — A commercial penetration testing framework originally designed for red teams that attackers widely abuse as a command-and-control platform; its "beacons" establish encrypted, hard-to-detect communication channels between a compromised host and the attacker's remote infrastructure.
BloodHound — An open-source Active Directory reconnaissance tool that graphs trust relationships, group memberships, and privilege delegation paths within a Windows domain, helping attackers (and defenders) visually identify the shortest route from a low-privilege foothold to domain administrator access.
