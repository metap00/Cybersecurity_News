💡 Today I Learned: Living off the Land ▶
"Living off the Land" (LotL) is an attack strategy where adversaries rely exclusively on legitimate tools already installed on a target's system — such as PowerShell, Windows Management Instrumentation (WMI), or macOS's built-in scripting engines — to carry out malicious activity, rather than dropping custom malware onto disk. Because these utilities are trusted by the operating system and expected to run, traditional antivirus and endpoint-protection tools often miss the attack entirely, leaving only subtle behavioural anomalies in logs as clues. Defenders counter LotL techniques by implementing strict application whitelisting, monitoring for unusual uses of scripting interpreters (for example, PowerShell spawning outbound network connections at odd hours), and deploying behavioural-analytics tools that flag deviations from normal user and system patterns.
📖 Glossary: SIEM · IAB · LotL ▶
SIEM — Security Information and Event Management: a platform that aggregates log data from across an organisation's entire IT estate — servers, firewalls, endpoints, and applications — and applies correlation rules and machine learning to detect suspicious patterns in near-real time.
IAB — Initial Access Broker: a cybercriminal who specialises in breaking into corporate networks and then selling that access on underground forums to ransomware operators or other threat actors, rather than conducting the full attack themselves.
LotL — Living off the Land: an attack technique that uses legitimate, pre-installed system tools (such as PowerShell or WMI) to execute malicious commands, making detection harder because no foreign malware is written to disk.
