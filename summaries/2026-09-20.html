💡 Today I Learned: Typosquatting ▶
Typosquatting is an attack technique where criminals register domain names that are deliberate misspellings or visual lookalikes of legitimate websites — for example, paypa1.com instead of paypal.com or arnazon.com instead of amazon.com. When a user miskeys a URL in the browser bar or clicks on a deceptively named link, they arrive at the attacker's site, which is often a pixel-perfect clone designed to harvest login credentials, serve malware, or sell counterfeit goods. Organisations defend against typosquatting by proactively registering common misspellings of their own domains, deploying brand-protection monitoring services that scan new domain registrations, and educating users to check the address bar carefully before entering any sensitive information.
📖 Glossary: AiTM · ZTNA · DAST ▶
AiTM — Adversary-in-the-Middle: a real-time phishing technique that proxies authentication traffic between a victim and a legitimate site to steal session cookies, enabling attackers to bypass multi-factor authentication without knowing the user's password.
ZTNA — Zero Trust Network Access: a security framework that grants access to specific applications only after verifying user identity and device health on every request, replacing the older model of trusting anything already inside the network perimeter.
DAST — Dynamic Application Security Testing: automated security scanning of a live, running web application by simulating external attacks such as SQL injection and cross-site scripting to discover vulnerabilities without access to source code.
