💡 Today I Learned: Egress Filtering ▶
Egress filtering is a network security practice where a firewall or proxy inspects and controls outbound traffic leaving a network, not just inbound traffic arriving at it. Most organizations focus heavily on blocking unwanted traffic coming in, but egress filtering catches malware that is already inside trying to "phone home" to a command-and-control server, or prevent sensitive data from being exfiltrated. By whitelisting only the outbound destinations a system legitimately needs to reach, defenders dramatically shrink the attack surface for data theft and malware beaconing.
📖 Glossary: Egress Filtering · Network Proxy ▶
Egress Filtering — The practice of inspecting and restricting outbound network traffic to prevent data exfiltration and block malware from contacting external command-and-control servers.
Network Proxy — An intermediary server that sits between clients and the internet, forwarding requests on their behalf while enforcing security policies such as URL filtering, TLS inspection, and access control.
